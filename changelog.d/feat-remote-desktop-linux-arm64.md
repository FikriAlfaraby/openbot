### Added

- Open the remote desktop of a Linux arm64 server, such as an Oracle A1 or AWS Graviton machine. Before,
  the desktop said that the runtime was missing on these servers.

### Changed

- Let a server have up to 100 members without a license. Before, a server without a license stopped
  at 3 members.
- Hide the Billing tab in Settings. A community server sells no plan or license.
