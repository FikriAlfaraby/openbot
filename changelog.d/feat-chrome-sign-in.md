### Added

- Give an agent's browser tab the sign-in of its site from a Chrome profile on your Mac. Open the page
  menu of the tab and select Sign in with Chrome, then the profile. Only the cookies of that site go to
  the tab, on this Mac or on a remote server.
- Let a browser profile of your Mac follow a Chrome profile. In Server settings › Browser profiles, open
  the profile's menu and select Follow Chrome profile. OpenBot copies every sign-in of that Chrome profile
  when it starts, and again when you select Sync from Chrome now.
- Open chat links in the built-in browser of a joined server too, when Settings › General › Open external
  links in is OpenBot. Before, that setting worked only for this computer's agents.
